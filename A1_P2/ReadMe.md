# Project Title

A0- BST 

## Description

This project implements a Splay Tree in C++ using a pointer-based binary search tree structure.
The implementation includes:

Insertion

Search with self-adjustment

Deletion

Tree visualization

Semi-splay (rotation-limited) optimization

Weighted splay with cache-like behavior

Rotation counting for performance analysis

## Getting Started

### Dependencies

* Installing IDE for C++
* A C++ compiler

### Installing

* Download or clone the project from GitHub. 
* Ensure all project files are in the same folder

### Executing program

* Open a terminal in the project folder
* Compile using the Makefile:
```
make
```
* Run the program with an input command file:
```
./mainsplay file.txt
```


## Help

If the program fails to run:

    Make sure all files are in the same folder.

    Make sure the terminal is in the project directory.

    Ensure the command file exists and is correctly formatted.
