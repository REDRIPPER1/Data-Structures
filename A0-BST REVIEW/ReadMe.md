# Project Title

A0- BST 

## Description

 This project implements Binary Search Tree (BST) in C++ using an array-based structure which supports insertion, search, deletion, traversals, checking if the tree is balanced, computing node heights, and detecting worst-case scenarios.

## Getting Started

### Dependencies

* Installing IDE for C++
* A C++ compiler

### Installing

* Download or clone the project from GitHub. 
* Ensure all project files are in the same folder

### Executing program

* Open a terminal in the project folder
* Compile using the Makefile:
```
make
```
* Run the program with an input command file:
```
./bst file.txt
```

*The program will execute insert, search, traversal, height calculation, balance check, deletation, node count, tree height, insert cost, search cost, and worst case detection

## Help

If the program fails to run:

    Make sure all files are in the same folder.

    Make sure the terminal is in the project directory.

    Ensure the command file exists and is correctly formatted.
